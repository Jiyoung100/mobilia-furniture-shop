# MOBILIA
취향에 맞는 가구를 탐색하고 구매할 수 있는 가구 쇼핑몰 팀프로젝트입니다.

## 프로젝트 개요
- **개발 기간:** [시작일 ~ 종료일]
- **개발 인원:** [인원]명
- **팀 저장소:** [팀 저장소 링크]
- **개인 담당:** [담당 기능 및 화면]

이 저장소는 팀프로젝트 결과물을 개인 포트폴리오 목적으로 정리한 저장소입니다. 상품 및 브랜드 데이터는 학습·시연용 더미 데이터입니다.

## 기술 스택
| 구분 | 기술 |
|---|---|
| Backend | Java, Spring Boot, Spring Security, Thymeleaf |
| Frontend | HTML, CSS, JavaScript, Bootstrap |
| Database | MySQL |
| UI 라이브러리 | Swiper, bxSlider |

## 주요 기능
- **상품 탐색:** 전체 상품, 공간별 가구, 브랜드별 상품 조회 및 검색
- **신상품:** 최근 등록된 상품 16개 조회 및 가격순 정렬
- **상품 상세:** 상품 정보, 평균 별점, 후기 개수, 관련 상품 조회
- **구매:** 수량 선택, 장바구니, 주문 및 주문조회
- **고객 서비스:** 상품 후기 및 Q&A
- **관리자:** 상품·회원·주문 관리, ADMIN·MANAGER 권한별 접근 제어
- **반응형 화면:** PC·모바일에 맞춘 메뉴 및 레이아웃

## 담당 작업
> 아래 항목 중 직접 구현하거나 수정한 작업만 남겨주세요.

### 상품 목록 및 상세 화면
- 상품 목록 및 신상품 페이지 구성
- 브랜드별 배너와 소개 문구 적용
- 상품 상세페이지 정보 정렬 및 구매 영역 UI 개선
- 평균 별점·후기 개수 표시 및 후기 영역 이동 링크 연결
- 재고에 따른 품절 표시와 수량 입력 비활성화 처리
- 관련 상품 슬라이더의 간격·글자 크기 및 페이지 표시 개선

### 공통 메뉴 및 관리자 화면
- 모바일 상단 메뉴와 장바구니 배지 정렬 개선
- 관리자 모바일 상단바 및 메뉴 구성
- 회원 정보 수정 화면의 공통 CSS 충돌 및 여백 수정
- ADMIN·MANAGER의 상품 관리 접근 권한 설정 수정
